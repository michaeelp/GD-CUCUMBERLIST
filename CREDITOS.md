# Créditos y fuentes

Proyecto de fans independiente. Geometry Dash y sus sprites pertenecen a RobTop Games.

- Pusab, Ryoichi Tsunekawa / Flat-it. Archivo OTF y licencia en `assets/fonts/`. Fuente: https://www.fontsquirrel.com/license/pusab
- Gavatar 1.0.0, código MIT. Licencia en `assets/Gavatar-LICENSE.txt`. https://github.com/Supernova3339/gavatar
- Sprites de iconos obtenidos del repositorio público de Gavatar; los recursos del juego pertenecen a RobTop.
- Rostros de dificultad del repositorio público GDBrowser-Maintained: https://github.com/yoann256/GDBrowser-Maintained/tree/main/assets/difficulties
- PIXI.js 7.4.3, MIT; React 19.2.6, MIT; Lucide, ISC.
- SDK de Firebase compat 9.22.1, alojado localmente desde su distribución oficial.
- Datos de GD consultados mediante los endpoints públicos `getGJUserInfo20.php`, `getGJUsers20.php` y `getGJLevels21.php`. Referencia: https://boomlings.dev/resources/server/user
- La integración de Sheets y el proyecto de Firebase son los proporcionados en el código original.
- Portal, cubo decorativo, paneles, botones, fondo, logo y sonidos Web Audio creados para esta interfaz.

Las licencias del código no se presentan como una cesión de derechos sobre los sprites originales del juego.
